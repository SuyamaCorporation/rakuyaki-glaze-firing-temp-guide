# 楽焼 うわぐすり焼成温度ガイド

長石・珪石・炭酸カルシウム・金属酸化物の成分比率をスライダーで入力すると、推定融点・焼成帯温度・釉薬質感・発色を自動計算するガイドアプリです。黒楽・赤楽・白楽のプリセットをワンクリックで呼び出せ、煙還元焼成の6工程チェックリストと焼成メモをlocalStorageに保存できます。

## 機能
- 釉薬成分（長石・珪石・炭酸Ca・金属酸化物）スライダー（自動正規化）
- 金属酸化物種類セレクター（酸化鉄・銅・コバルト・マンガン・なし）
- 推定融点・焼成帯・釉薬質感・発色の自動推定
- 黒楽・赤楽・白楽プリセットワンクリックロード
- 煙還元焼成チェックリスト（6工程・各手順コツ表示）
- 焼成メモのlocalStorage保存
